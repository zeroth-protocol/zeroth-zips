# ZIP-0001: Zeroth Improvement Proposal Process

- **Status:** Draft
- **Type:** Process
- **Created:** 2026-09-10

## Abstract
Defines the lifecycle, structure and review rules for Zeroth Improvement Proposals.

## Lifecycle
`Draft → Review → Accepted → Final`

Additional terminal states: `Rejected`, `Withdrawn`, `Superseded`.

## Required sections
Abstract; Motivation; Specification; Rationale; Backwards Compatibility; Security Considerations; Post-Quantum Considerations when relevant; Test Vectors / Conformance; Reference Implementation Status; License.

Acceptance of a ZIP does not itself imply deployment. Deployment requires applicable engineering, security and release gates.

Exploit-sensitive details remain private until coordinated disclosure is safe.
